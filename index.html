SERVICIOS

Especialidades técnicas y áreas de competencia profesional orientadas al desarrollo de soluciones informáticas fiables y mantenibles.

01

Arquitectura de Microservicios

Diseño e implementación de sistemas distribuidos bajo el patrón de microservicios con Spring Boot y Spring Cloud. Cada dominio encapsulado en un servicio independiente, comunicados mediante OpenFeign y expuestos por un API Gateway centralizado.

  • Spring Boot 3.x & Spring Cloud
  • API Gateway & Enrutamiento Dinámico
  • Spring Cloud OpenFeign (inter-service)
  • Patrón Database per Service
  • Docker Compose (orquestación local)
02

Backend & APIs RESTful con Java

Desarrollo de backends robustos en Java 17/21 con Spring Boot. Diseño de APIs RESTful con capas diferenciadas (Controller, Service, Repository), DTOs, manejo centralizado de errores, autenticación con BCrypt y documentación automática vía Swagger UI.

  • Java 17 / Java 21 (LTS)
  • Spring Data JPA & Hibernate
  • Spring Security 6 (BCrypt)
  • Springdoc OpenAPI (Swagger UI)
  • Lombok & Arquitectura por Capas
03

Bases de Datos Relacionales & PL/SQL

Modelado conceptual y lógico de datos con normalización hasta 3FN, diseño de esquemas en MySQL, PostgreSQL y Oracle. Programación procedural avanzada en PL/SQL: cursores, procedimientos almacenados, funciones, triggers y migraciones versionadas con Flyway.

  • PostgreSQL & MySQL 8
  • Oracle DB & PL/SQL (cursores, procedures)
  • Migraciones Flyway (versionado de esquemas)
  • Normalización 3FN & Modelado ER
  • Optimización de Queries e Índices
04

Desarrollo Web Full Stack

Construcción de interfaces web semánticas, responsivas y accesibles con HTML5, CSS3 y JavaScript modular. Integración directa con APIs REST propias para aplicaciones de una sola página sin dependencias de frameworks pesados.

  • HTML5 Semántico & CSS3 (Flexbox, Grid)
  • JavaScript ES6+ Modular (Vanilla)
  • Diseño Responsivo & Accesibilidad
  • Integración REST API (Fetch / Axios)
  • Single Page Applications (SPA)
05

Contenerización & DevOps Básico

Empaquetado de servicios en contenedores Docker con builds multi-stage optimizados para Java. Orquestación de entornos completos con Docker Compose, gestión de redes bridge, volúmenes persistentes y variables de entorno por servicio.

  • Docker & Dockerfile multi-stage
  • Docker Compose (multi-contenedor)
  • Git & GitHub Flow (ramas, PRs)
  • Maven Wrapper & gestión multi-módulo
  • Variables de entorno & configuración
06

Testing, Calidad & Clean Code

Escritura de pruebas unitarias sobre capas Service y Controller con JUnit 5 y Mockito. Medición de cobertura con Jacoco. Aplicación de principios SOLID y Clean Code para mantener bases de código legibles, desacopladas y evolutivas a largo plazo.

  • JUnit 5 & Mockito (Spring Boot Test)
  • Jacoco (cobertura de pruebas)
  • Principios SOLID & Clean Code
  • Documentación técnica & Swagger
  • Detección y corrección de bugs
